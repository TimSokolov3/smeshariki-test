# Тесты на характер 🎉

Мини-сайт с несколькими шуточными тестами-квизами («кто ты из...», «какой ты...»). Каждый тест — 8 вопросов, подсчёт очков и экран результата с оригинальными нарисованными SVG-иллюстрациями. Сделано на чистом HTML/CSS/JS, без сборщиков и фреймворков.

🔗 Сайт: https://timsokolov3.github.io/smeshariki-test/

## Какие тесты есть

- 🌈 **Кто ты из Смешариков?** — 9 персонажей (`smeshariki.html`, `smeshariki-data.js`)
- 🍺 **Какое ты пиво?** — 6 сортов (`beer.html`, `beer-data.js`)
- 🕷️ **Какой ты Человек-паук?** — 3 актёра (`spiderman.html`, `spiderman-data.js`)
- 🥟 **Какой ты эчпочмак?** — 4 начинки (`echpochmak.html`, `echpochmak-data.js`)

## Структура проекта

- `index.html` — главная страница с меню выбора теста
- `engine.js` — общий движок квиза (вопросы, подсчёт очков, экран результата, конфетти) — один на все тесты
- `<название>.html` — страница конкретного теста (подключает `engine.js` + свой `-data.js`)
- `<название>-data.js` — данные теста: персонажи/результаты, вопросы с очками, функция отрисовки SVG-аватарки
- `style.css` — общее оформление и анимации для всех страниц
- `.gitignore` — список файлов, которые git не должен отслеживать

## Как добавить новый тест

1. Скопировать любой `*-data.js` за образец, поменять `ITEMS`, `QUESTIONS` и функцию `avatarSvg`
2. Создать `<название>.html` по образцу существующих (подключает `engine.js` и новый `-data.js`)
3. Добавить плитку со ссылкой на новый тест в `index.html`

## Как посмотреть локально

Открыть `index.html` в браузере (двойной клик по файлу, или через VS Code — правой кнопкой → Open with Live Server / Open in Browser).

## Как обновить сайт

```
git add -A
git commit -m "Описание изменений"
git push
```

GitHub Pages сам пересобирает сайт после `push` в ветку `main` (обычно занимает 1–2 минуты).
