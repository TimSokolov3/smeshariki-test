# Кто ты из Смешариков? 🌈

Мини-тест на 8 вопросов, определяющий, какой персонаж из «Смешариков» тебе ближе по характеру. Сделан на чистом HTML/CSS/JS, без сборщиков и фреймворков.

## Структура проекта

- `index.html` — каркас страницы
- `style.css` — оформление и анимации (градиентный фон, летающие бабочки, карточки)
- `script.js` — логика теста: вопросы, подсчёт очков, экран результата
- `.gitignore` — список файлов, которые git не должен отслеживать (например, `.DS_Store`)

## Как продолжить (следующий шаг)

1. Открыть терминал в VS Code (`Terminal → New Terminal`)
2. `cd "/Users/timsokolov/Downloads/Смешарики тест"`
3. Создать токен на https://github.com/settings/tokens/new (scope: `repo`)
4. Выполнить `git push -u origin main`, в качестве пароля вставить токен
5. После успешного push — включить GitHub Pages в настройках репозитория (Settings → Pages → Source: `main`)

## Как посмотреть тест локально

Просто открыть `index.html` в браузере (двойной клик по файлу, или через VS Code — правой кнопкой → Open with Live Server / Open in Browser).
